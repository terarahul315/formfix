Agniveer Photo Upload Guide: Name & Date Slate

Published on November 28, 2026 • 4 min read

Agniveer Army rally ke liye register karte waqt sabse zyada problem photo upload mein aati hai. Indian Army ka rule hai ki photo ke saath ek slate hona chahiye jisme candidate ka Name aur Date of Photo (DOP) likha ho. Is guide mein hum aapko batayenge ki ye kaise banayein.

Agniveer Photo Requirements

  • Photo Type: Passport size, recent (6 mahine se purana nahi)
  • Background: Plain white ya light colored
  • Slate: Photo ke neeche safed patti (white strip) mein Name aur Date likha hona chahiye
  • Name Format: CAPITAL LETTERS mein
  • DOP Format: DD-MM-YYYY (jaise 28-11-2026)

Name & Date Slate Photo Kaise Banayein?

Agar aap paas koi studio nahi jaana chahte, toh aap FormFix use kar sakte hain. Ye 100% free hai aur photo kisi server par upload nahi hota.

  1. FormFix homepage par jayein.
  2. "Photo" mode select karein.
  3. Apna photo upload karein.
  4. "Optional: Print Name & Date on Photo" section mein apna Name aur DOP daalein.
  5. Target size (jaise 50KB) aur dimensions (jaise 413x531) set karein.
  6. "Process Image" par click karein.
  7. Photo ke neeche safed strip mein aapka Name aur Date apne aap add ho jayega.

Common Mistakes (Inse Bachein)

  • Name galat format mein: Hamesha CAPITAL LETTERS use karein.
  • Date galat format: DD-MM-YYYY hi use karein (jaise 28-11-2026, 11/28/2026 nahi).
  • Slate na hona: Bina Name aur Date ke photo reject ho sakta hai.
  • Blurry photo: Photo clear aur sharp hona chahiye.
