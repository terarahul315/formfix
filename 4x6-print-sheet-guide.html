4x6 Print Sheet Kya Hoti Hai aur Kaise Banayein?

Published on November 28, 2026 • 4 min read

Agar aapne kabhi studio se passport photo banwaya hai, toh aapne dekha hoga ki wo ek badi sheet par 6-8 photos print karke dete hain. Isi ko 4x6 print sheet kehte hain. Is article mein hum batayenge ki ye kya hai aur aap ise ghar par kaise bana sakte hain.

4x6 Print Sheet Kya Hai?

4x6 inch (4 by 6 inch) ek standard photo print size hai. Is sheet par 6 passport size photos (2 rows x 3 columns) arrange ki jaati hain. Ye 300 DPI (dots per inch) par 1800 x 1200 pixels hoti hai.

Ghar par 4x6 Sheet Kaise Banayein?

FormFix ka 4x6 Sheet tool use karein. Ye free hai aur aapka photo server par upload nahi hota.

  2. "4x6 Sheet" mode select karein.
  3. Apna passport photo upload karein.
  4. Target size (jaise 450KB) set karein.
  5. "Process Image" par click karein.
  6. Download karein aur kisi bhi photo studio ya print shop par print karwayein.
